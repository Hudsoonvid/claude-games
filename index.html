Claude Arcade

Free, open-source and original games — every one playable with touch, mouse or trackpad, keyboard, and a controller. Works offline once installed.

    Install on your device

    iPhone & iPad
    1. Open this page in Safari.
    2. Tap Share, then Add to Home Screen.
    3. Launch from the home screen for full-screen play. On iPad a trackpad, mouse or paired controller all work.
    Mac
    1. Safari: File → Add to Dock. Chrome or Edge: the install icon in the address bar.
    2. Trackpad gestures work in every game: two-finger swipe moves tiles in 2048, rotates in Hextris, and pans / pinch-zooms in Slingstone.
    Steam Deck & SteamOS devices
    1. In Desktop Mode install Chrome or Chromium from Discover, then download launchers/steam-deck.sh from this project and make it executable.
    2. In Steam choose Add a Non-Steam Game and pick that script. Set its launch option to this page's address.
    3. It opens full-screen in Gaming Mode. D-pad or stick picks a game, A starts it, hold View/Select to come back here.
    Linux & Windows
    1. Chrome, Chromium or Edge: use the install icon in the address bar to get a windowed app.
    2. On Linux you can also run launchers/arcade.sh <address>, or copy launchers/claude-arcade.desktop into ~/.local/share/applications.
    Android
    1. Open in Chrome and choose Install app (or Add to Home screen) from the menu.
    Bundled games keep their original licences — see credits & licences.
